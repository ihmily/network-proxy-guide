# 第21章 合规使用建议

科学上网需要在法律框架内合理使用。本章介绍相关法律法规和使用边界。

## 21.1 法律法规认知

### 21.1.1 相关法律条文

**主要法律依据：** 下表便于查找原文，具体适用须结合联网方式、服务对象和实际行为判断。

| 文件与官方文本 | 本章相关内容 |
|---|---|
| [《中华人民共和国计算机信息网络国际联网管理暂行规定》](https://xzfg.moj.gov.cn/mobile/law/detail?LawID=1713) | 第六条规定国际出入口信道；第十条涉及用户接入；第十四条列出违反相关条款的行政责任。该规定已于2024年修订，原版所写“邮电部国家公用电信网”不是现行第六条措辞。 |
| [《计算机信息网络国际联网安全保护管理办法》](https://xzfg.moj.gov.cn/mobile/law/detail?LawID=1198) | 第四至七条涉及网络安全、信息与通信秘密；第十三条涉及公用账号管理；第二十条规定部分违法行为的处罚。 |
| [国家法律法规数据库](https://flk.npc.gov.cn/) | 可查询《刑法》及其他适用法律。原版将第285—287条分别概括为单一罪名过于简化，应以各条现行全文和具体构成要件为准。 |

**关键点理解：** “翻墙”“VPN”等口语或软件名称本身不能替代法律判断；个人学习、工作等用途也不能自动豁免联网方式、内容和数据处理要求。对外提供连接、跨境经营与个人使用涉及的规则不完全相同，应分别核对。

### 21.1.2 执法实践

**不要把传闻当作处罚规则。** 原版的“一般不追究”“单纯个人使用极少追究”以及“罚款一般5000—15000元”缺乏可适用于所有场景的依据。处理机关、适用条款与结果取决于具体事实。

| 核对事项 | 官方依据与读法 |
|---|---|
| 非法定信道等联网方式 | [《暂行规定》](https://xzfg.moj.gov.cn/mobile/law/detail?LawID=1713)第十四条对违反第六、八、十条的行为规定责令停止联网、警告，可以并处**15000元以下**罚款；不是“通常罚5000—15000元”。 |
| 网络信息与安全行为 | [《安全保护管理办法》](https://xzfg.moj.gov.cn/mobile/law/detail?LawID=1198)第二十条区分个人与单位的罚款上限，并规定其他可能措施；不能与上项混为同一处罚标准。 |
| 跨境经营 | [工业和信息化部通知](https://www.miit.gov.cn/jgsj/xgj/wjfb/art/2020/art_ac2095b32d054e22a03e8154c3a44d50.html)针对未经批准开展跨境经营活动作出要求；[主管部门答问](https://www.cac.gov.cn/2017-01/26/c_1120381529.htm)进一步解释了其规范对象和企业办公自用场景。 |

看案例时记录事实、地区、日期、处罚决定和所引条款；不要由少量案例推断某类个人用途“安全”或“必然违法”。遇到具体法律问题，应查现行官方文本并咨询有资质的专业人士。

### 21.1.3 合法替代方案

**正规渠道：** 下列是可咨询的接入方式，不代表仅凭渠道名称就自动合规；须核对资格、用途、合同及所在地要求。

```
1. 教育科研网
   适用：高校师生、科研机构
   方式：教育网国际出口
   特点：
   ✓ 通过正规渠道申请并核对授权
   ✓ 学术资源丰富
   ✓ 速度较快
   限制：依学校网络制度及账号授权使用

2. 企业专线
   适用：企业、外资机构
   方式：申请MPLS VPN等
   特点：
   ✓ 在获批用途与合同范围内使用
   ✓ 稳定可靠
   ✓ 技术支持
   限制：
   - 成本高昂
   - 需要企业资质
   - 仅限业务使用

3. 官方国际业务
   运营商：中国电信、联通、移动
   产品：国际业务套餐
   特点：
   ✓ 通过正规渠道申请并核对授权
   ✓ 正规服务
   限制：
   - 可能较慢
   - 价格不菲
   - 功能受限

4. 出国访问
   方式：出国时正常访问国际互联网
   特点：
   ✓ 按访问地规则和服务条款使用
   ✓ 仍应遵守访问地法律与平台规则
   限制：需要出国，并遵守访问地要求
```

## 21.3 风险防范意识

### 21.3.1 个人信息保护

**隐私保护原则：**

```
1. 最小化原则
   - 按服务要求如实提供必要信息
   - 允许使用昵称时避免过度披露
   - 避免暴露个人详情
   - 谨慎上传照片

2. 分隔原则
   - 国内外账号分离
   - 不同平台不同身份
   - 按场景控制账户关联信息
   - 独立密码管理

3. 匿名原则
   - 使用专用且可恢复的邮箱
   - 仅使用合法取得的联系方式
   - 选择合规且可核对账单的支付方式
   - 按风险需求选择隐私工具，不假设叠加必然更安全

4. 加密原则
   - 敏感通信加密
   - 使用端到端加密
   - 文件加密存储
   - 安全删除数据

实践：
- 不在社交媒体暴露真实身份
- 不使用真实照片做头像
- 不关联国内社交账号
- 定期检查账户授权与隐私设置
```

**防范措施：**

```
行为安全：

   - 不发表极端言论
   - 理性讨论
   - 尊重他人

2. 保护隐私
   - 不暴露位置

   - 注意照片EXIF
   - 谨慎社交

3. 甄别信息
   - 核实信息来源
   - 不轻信传言
```

```
- 保留必要记录，按适用程序处置并寻求法律咨询

- 配合调查

建议：
- 只保留业务必要信息
- 使用全盘加密
- 按适用要求管理记录与保留期限
- 了解自己的权利

预防措施：
✓ 建立应急联系方式
✓ 定期备份重要数据
✓ 分散风险
✓ 保持处置记录可追溯
✓ 遵守法律
```
