    📚 科学上网完全指南¶

    面向初学者与进阶读者的网络代理技术教程

    在线阅读： 科学上网完全指南

    📖 关于本书¶

    《科学上网完全指南》是一套面向初学者与进阶读者的网络代理技术教程，分为基础知识、主流协议与工具、高级配置（订阅与节点管理、分流规则）、服务器搭建、安全与隐私、故障排查、最佳实践七个部分，共 21 章，并配有术语表、资源索引和参考文献三项附录。全书从网络与代理原理讲起，结合客户端配置、服务器部署、安全与隐私保护、网络测试及不同场景的使用与成本优化，提供操作示例和排查思路。软件功能、配置格式和外部资源可能随版本变化；动手实践前请核对相关项目的官方文档与软件版本，评估安全与隐私风险，并遵守所在地法律法规。

    ✨ 核心特点¶

    • 🎯 系统全面 - 从零基础到高级应用的完整知识体系
    • 💻 实战导向 - 大量配置示例、命令脚本、实战案例
    • 📝 深入浅出 - 原理讲解 + 实践操作，循序渐进
    • 🔒 注重安全 - 专门章节讲解安全防护和隐私保护
    • ⚖️ 合规意识 - 强调法律法规和合理使用边界

    • 文档文件数：26个（含首页和大纲）
    • 正文章节：21章
    • 附录资料：3个

    📚 章节概览¶

    第一部分：基础知识篇¶

    介绍科学上网的基本概念、网络基础知识和核心技术原理，为后续学习打下坚实基础。

    第二部分：主流协议与工具篇¶

    介绍 Shadowsocks、VMess、VLESS、Trojan、Hysteria 2 等代理协议、WireGuard VPN、V2Ray/Xray 与 mihomo 等工具，以及 REALITY 等传输安全机制；并说明各平台客户端的使用方法。

    第三部分：高级配置篇¶

    面向已经会使用客户端的代理使用者，介绍订阅管理和分流规则，帮助读者按实际需要调整客户端的使用方式。

    第四部分：服务器搭建篇¶

    从 VPS 选购到服务器部署，介绍 Xray 安装脚本、手动搭建、3X-UI 面板管理以及域名与证书配置。

    第五部分：安全与隐私篇¶

    重点关注网络安全防护、隐私保护和日志管理，包括浏览器指纹、WebRTC 与 DNS 等隐私设置。

    第六部分：故障排查篇¶

    系统化的故障诊断方法和网络测试工具使用指南。

    第七部分：最佳实践篇¶

    针对不同应用场景的最佳实践方案，以及成本优化和合规使用建议。
